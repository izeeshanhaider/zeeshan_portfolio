Citara

Ali Square · German engineering firm · 2025–2026 · Project lead
95%retrieval accuracy
On-premisesno data leaves the client network

The challenge

The client's engineers spent hours manually searching extensive technical standards. For confidentiality reasons, the documents could not leave their network.

The solution

An on-premises retrieval platform that answers questions directly from the standards and cites the exact clause behind each answer. I led its delivery from document ingestion to production.

Technical approach

Ingestion. Layout-aware OCR and clause-boundary chunking, keeping each clause intact and linked to its parent section in a Neo4j knowledge graph.

Retrieval. HyDE query expansion combined with full-text and vector search, with graph traversal adding parent sections and related clauses as context.

Access control. Role-based permissions enforced at the graph level, so restricted content is never retrieved.

Result

95% retrieval accuracy on the client's ground-truth question set, with per-query failure analysis guiding each improvement.

Neo4j · LangGraph · LangChain · MinerU · Docling · Mistral OCR · vLLM · Django

On-premises LLM inference

Ali Square · Citara model serving
9 s → 4 sresponse time
FP8on vLLM

The challenge

A smaller model responded quickly but lacked accuracy on dense technical content. A larger model delivered higher accuracy but responded more slowly.

The solution

Keep the larger model and optimize how it is served.

Technical approach

Prototyping. Built and iterated on the pipeline with Qwen3.5-9B on a 12 GB RTX 3060.

Model selection. Moved production to Qwen3.8-27B after evaluation on the client's real queries.

Optimization. Served the 27B model in FP8 precision on vLLM, entirely on the client's infrastructure.

Result

Response time fell from 9 seconds to 4, with all inference on the client's infrastructure.

vLLM · FP8 · Qwen3.8-27B · Qwen3.5-9B · Ollama

YardLens

Ali Square · Logistics yard · Model development
75% → 90%detection accuracy
0operators needed at the gate

The challenge

Gate activity at the client's logistics yard was logged manually.

The solution

A vision system that detects and records vehicles, equipment, license plates and shipment identifiers automatically. I owned model training and evaluation within the delivery team.

Technical approach

Detection and tracking. Retrained YOLO models on annotated yard data and tuned ByteTrack multi-object tracking.

Extraction. OCR reads license plates and shipment identifiers into structured records.

Deployment. GPU inference on AWS EC2 with Docker and GitHub Actions CI/CD.

Result

Detection accuracy improved from 75% to 90%, and gate logging runs without an operator.

YOLO · Ultralytics · ByteTrack · OpenCV · AWS EC2 · Docker · GitHub Actions
